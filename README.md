# Northstar · Project 52: Ironwall — Winter Rebuild V66.2

November 18, 2026–February 28, 2027. A 103-day bulk-and-leg rebuilding cycle with a separate earned 52-brick milestone.

## Daily use

Today has six permanent checks, one completion percentage, one Body Status card with five sliders, and two collapsed optional notes. No workout programming or set-by-set logger. Photos has three current slots; older photos stay privately archived.

## Direct strength progress

Goals → Strength Progress accepts an exercise, date, weight, and reps. Pull-up capacity uses total reps plus actual duration. Add a custom exercise, including a side-specific leg benchmark, without creating a workout program. Save explicitly; edit entries or archive mistakes with revision history retained.

The ledger shows cycle baseline, latest entry, and target. It compares like-for-like reps or duration; a short pull-up test is never extrapolated into one hour. Logging alone never completes a strength target. Monthly reviews read the same entries, with no second strength input.

Earned targets use retained qualifying proof, separate from latest performance. A deload does not erase an earned target; correcting or archiving the only qualifying proof does. All six standing targets complete the automatic goal and its achievement. Entries outside November 18–February 28 remain historical, not winter progress.

Failed strength saves roll back the pending ledger change while retaining form input. Retry does not duplicate an entry or block a custom exercise. Repeated taps are guarded during saving; edits/removals retain private revision history. Reward choices, budgets and acquisition history survive normalization, including the Paradox alternative within the existing single-disc cap.

The private restore carries personal career, financial, faith, recovery, and family checklists. The public shell has no personal task seed, account balances, photos, or private backup data.
